Configured media behavior

  • Voice: local STT (`faster-whisper`, model `base`) enriches the Telegram message.
  • Voice transcript raw capture is enabled at `/home/ubuntu/vault/inbox/raw`.
  • Raw audio is deleted after transcription; retention is off.
  • Photos and videos are available to the agent/vision tools; they do not have a configured automatic vault-ingest path.

What is actually durable

  • Hermes session + private memory: Hermes stores, separate from Obsidian.
  • Obsidian vault: human-readable transcripts, notes and synthesis.
  • Kanban: durable active work queue, when explicitly used.
  • Each project `.agents/`: accepted project state, audit, attribution and handoff—not a per-message auto-write.

Fan-out / fan-in

  • Kanban auto-decomposition is enabled and dispatcher runs in the gateway every 60 seconds.
  • Telegram's current toolset does not expose `kanban` to the ordinary agent turn; `/kanban` remains an explicit routing surface.
  • Delegation is available to Telegram, capped at two concurrent child agents and one spawn depth.
  • Acceptance/reconciliation before project-memory update is the recorded project-harness policy.
